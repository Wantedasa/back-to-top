# Back to Top ⬆️

A button that appears after scrolling and smoothly returns to the top.

## What it is
A back-to-top button that stays hidden until you scroll down, then fades in. Clicking it smoothly scrolls to the top. Listens to scroll and uses requestAnimationFrame-friendly smooth scrolling.

## Usage
```js
window.scrollTo({top:0, behavior:'smooth'})
```
